1. WHAT IS ORIGINAL WORK
------------------------
Everything that makes up the simulator itself is written for this project:

  * all C++ source code in src\ (the flight model, the city generator, the
    landmarks, the missions, the HUD, the tools),
  * all 3D geometry - the aircraft, every building, road, bridge, tree, vehicle
    and landmark is generated by code at start-up, not loaded from a model file,
  * the flight model, the missions, the cinematic demo and the interface.

No model files, sound files or map data are used. Textures are optional and
described in section 3.

3. PHOTOGRAPHIC TEXTURES (optional, assets\textures\)
-----------------------------------------------------
105 JPEG files from Poly Haven (https://polyhaven.com), used under the
Creative Commons CC0 1.0 Universal licence (public domain dedication):

  https://creativecommons.org/publicdomain/zero/1.0/

They cover plaster, paint, concrete, brick, tile, timber, bamboo, corrugated
iron, roof tiles, thatch, grass, paddy, soil, mud, gravel, sand, rock and river
pebbles, asphalt and paving, bark and foliage. The list of files, the Poly Haven
asset each came from and its resolution is in assets\textures\_sources.txt;
tools\get_textures.ps1 re-downloads them.

CC0 places the textures in the public domain, so no attribution is legally
required; they are credited here as a matter of academic practice. Poly Haven
asks that credit be given where possible: "Textures from Poly Haven (CC0)".

Two things are not photographs:
  * the river water, which is generated in code (a teal ripple field with
    glints) because no CC0 water surface tiled well enough;
  * the runway and apron asphalt, which are also generated, and act as the
    fallback when no photo is loaded.
Everything else in the world - geometry, HUD, signs, aircraft - was never a
file at all.

The textures are optional. The game loads them at start-up and falls back to
its own flat colours and procedural noise when assets\ is missing, in which
case no third-party content is used at all.


4. THE BILLBOARD ARTWORK (assets\textures\imran_billboard.jpg)
---------------------------------------------------------------
The billboard artwork in this folder - "IMRAN INTERNATIONAL AIRLINES"
(imran_billboard.jpg), "AL-AMIN ENTERPRISES" (alamin_billboard.jpg) and the
group photograph (photo_billboard.jpg) - was produced for this project and is
part of it, covered by the same copyright as the source code in section 1. It
is not third-party material. Replace any of those files with your own image and
rebuild if a different design is wanted; if a file is missing the sign is drawn
in code instead.

5. HOW TO REBUILD FROM SOURCE
-----------------------------
See README.md. The short version, from the project folder:

  build.bat                 rebuilds SylhetAttack.exe (Code::Blocks or
                            Dev-C++ MinGW; freeglut is rebuilt automatically
                            from the vendored source if the static library is
                            missing)
  run.bat                   builds if needed, then launches the game
